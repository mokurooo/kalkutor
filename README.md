Kalkulator JavaFX

Kalkulator sederhana dengan tampilan biru-putih.

Cara Menjalankan
Buka proyek di NetBeans (pastikan JavaFX sudah ditambahkan).
Klik kanan Kalkulator2.java, lalu pilih Run File (Shift + F6).
Cara Memakai
Tekan angka yang diinginkan.
Tekan operator (+, -, *, /).
Tekan angka kedua.
Tekan = untuk melihat hasil.
Tekan AC untuk menghapus semuanya.

Contoh: 12 + 5 berarti tekan 1, 2, +, 5, =. Hasilnya 17.
